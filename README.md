# 라노 OS

내 에이전트 조직을 운영하는 맥용 데스크톱 앱입니다.
사용자 → **라노**(리더 중의 리더) → **미션별 리더** → **팀원** 순서로 일이 흐르고,
쓰기·커밋·삭제 같은 일은 모두 **승인함**에서 내가 승인한 뒤에만 실행됩니다.

- **대화**: 라노에게 일을 말하면 알맞은 미션 리더에게 맡기거나, 새 미션 구성안을 제안합니다
- **현황판**: 미션마다 리더와 팀원이 일하는 모습을 사무실 화면으로 봅니다
- **승인함**: 팀 구성안, 파일 쓰기, 커밋, 기획 결정(안 고르기)을 승인하거나 반려합니다
- **결과물함**: 끝난 과제의 결과물을 모아 봅니다
- **조직**: 미션(작업 폴더·권한·팀), 인재풀(역할), 스킬, 외부 연결(Confluence 같은 회사 서비스)을 관리합니다
- **휴대폰**: 텔레그램 봇으로 밖에서도 라노와 대화하고 승인합니다

> 📘 **처음 쓰시나요? [사용 가이드](GUIDE.md)** 에 설치부터 첫 미션, 승인, 스킬, 외부 연결, 휴대폰 연결까지 순서대로 적어 두었어요.

## 프로그램과 내 데이터

이 저장소는 **프로그램**만 담고 있습니다. 내 설정·미션·기억·기록은 **데이터 폴더**(기본 `~/rano`)에 따로 저장되고,
앱을 처음 켜면 `defaults/` 의 기본 틀로 데이터 폴더가 만들어집니다. 데이터 폴더 위치는 환경변수 `RANO_ROOT` 로 바꿀 수 있습니다.

구역은 두 가지입니다.
- **회사** 구역: 작업 폴더를 `~/work` 아래에서 고릅니다
- **개인** 구역: 작업 폴더를 `~/personal` 아래에서 고릅니다

두 구역의 미션은 서로의 폴더를 읽지도 쓰지도 못합니다. 구역 폴더 위치는 데이터 폴더의 `config/rano.json` 에서 바꿀 수 있습니다.

## 필요한 것

- Apple Silicon 맥 (macOS)
- Node.js 20 이상, git
- Claude 계정(Pro·Max) 또는 Anthropic API 키

## 받아서 바로 쓰기 (권장)

1. 이 저장소의 **Releases** 에서 `rano-os-<버전>-mac-arm64.zip` 을 받아요
2. 압축을 풀고 `라노 OS.app` 을 `응용 프로그램` 폴더로 옮겨요
3. 처음 한 번은 맥이 "확인되지 않은 개발자" 경고를 띄워요 (Apple 개발자 인증서로 서명하지 않은 앱이라서예요)
   - 앱을 더블클릭 → 경고 창에서 **완료** → **시스템 설정 › 개인정보 보호 및 보안** 맨 아래 "라노 OS" 옆 **그래도 열기** → 암호 입력
   - 또는 터미널에서 한 번: `xattr -dr com.apple.quarantine "/Applications/라노 OS.app"`
4. 앱이 켜지면 처음 설정 안내를 따라가요. 그다음은 [사용 가이드](GUIDE.md)를 보세요

git 이 없다는 창이 뜨면 안내대로 "개발자 도구"를 설치해 주세요 (기억 자동 저장과 리포 작업에 써요).

## 직접 만들기

```bash
git clone <이 저장소 주소> rano-os
cd rano-os
npm install
npm run package        # out/라노 OS-darwin-arm64/라노 OS.app 이 만들어집니다
```

만든 앱을 `응용 프로그램` 폴더로 옮겨 실행합니다. 개발 중에는 `npm start` 로 바로 켤 수 있습니다.
배포용 zip 은 `npm run release` 로 만들어요 (`out/rano-os-<버전>-mac-arm64.zip`).

## 처음 켰을 때

1. 이름·호칭·소속·개발 경험을 적어요 (라노가 설명 수준을 맞춰요)
2. 회사·개인 구역 폴더를 골라요
3. Claude 계정을 연결해요: Claude 구독(Pro·Max)이나 Console 계정으로 로그인하거나, API 키를 넣어요.
   로그인은 브라우저에서 하고, 화면에 나온 코드를 앱에 붙여 넣으면 돼요. 나중에는 오른쪽 위 **Claude** 버튼에서 바꿀 수 있어요.
   API 키는 맥 키체인으로 암호화해서 데이터 폴더(`runs/secrets`)에만 저장해요.

## 스킬 (일하는 법)

조직 탭 **스킬**에서 역할에게 스킬을 줄 수 있어요. 라노 OS 기본 스킬은 엑셀(rano-xlsx)·워드(rano-docx)·파워포인트(rano-pptx)·PDF(rano-pdf)예요.
문서 스킬은 [문서 도구 설치]로 데이터 폴더(`tools/python`)에만 파이썬 도구를 설치한 뒤 써요(맥 전체 설치 아님).
다른 스킬은 GitHub 주소나 폴더에서 가져올 수 있고, 넣기 전에 파일·내용·라이선스를 먼저 보여 줘요. 스킬로 명령을 실행할 때도 승인함을 거쳐요.

## 안전 원칙

- 외부로 여는 포트나 서버가 없습니다. 앱은 이 맥 안에서만 동작합니다 (휴대폰 연결은 맥이 텔레그램에 먼저 접속하는 방식)
- 비밀 키·인증 파일·`.env` 계열은 차단 목록으로 막혀 있어 리더와 팀원이 열 수 없습니다
- 작업 폴더의 쓰기·커밋·push·삭제는 파일 하나까지 승인함을 거칩니다
- 외부 연결의 쓰기·실행과 비밀이 보일 수 있는 조회도 승인함을 거치고, 사람마다 다른 키는 키체인으로 암호화해 둡니다
