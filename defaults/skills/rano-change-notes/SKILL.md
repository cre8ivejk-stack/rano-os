# 바뀐 내용 쉬운 말 정리 (rano-change-notes)

기술 변경을 쓰는 사람·운영하는 사람이 읽을 수 있게 바꾼다.

## 모을 곳 (읽기만)
- `git log --since=<날짜> --oneline`, `git log <이전>..<이후> --stat`, `git diff --stat` (읽기 명령)
- 미션 홈의 `outputs.md`, `memory/결정로그.md`
- 지시에 적힌 기간·버전. 없으면 "마지막 배포(태그) 이후"로 하고 맨 위에 적는다.

## 틀
```markdown
# <서비스·미션> 바뀐 내용 (<기간 또는 버전>)

## 한 줄 요약
<이번 변경으로 쓰는 사람이 느끼는 가장 큰 차이>

## 쓰는 사람에게 달라지는 것
- <화면·기능 기준 설명> (관련: <메뉴·화면>)

## 운영·데이터에 달라지는 것
- <배치 시각, 표 구조, 설정 등> — 할 일: <있으면>

## 조심할 것
- <되돌리기 어려운 변경, 같이 바꿔야 하는 것>  (없으면 "없음")

## 자세히 (개발용)
| 커밋 | 내용 |
|---|---|
```

## 지킬 것
- "리팩터링", "핫픽스" 같은 말은 쉬운 말로 풀어 쓴다(예: "속은 정리했고 겉 동작은 같아요").
- 커밋 메시지만 보고 짐작하지 말고, 의미가 애매하면 바뀐 파일을 열어 확인한다. 확인 못 한 것은 "확인 필요".
- 배포·push 는 하지 않는다. 결과는 시안 폴더에 `바뀐내용_<YYYYMMDD>.md` 로 만든다.
- 비밀 값·내부 서버 주소는 넣지 않는다.
