# Confluence 문서 틀 (rano-confluence-doc)

사내 위키에 붙여 넣기 좋은 문서 초안을 만든다. **게시·수정은 하지 않는다.** 실제로 올려야 하면 리더가 request_approval(kind: external)로 먼저 묻는다.

## 문서 종류별 구성

### 1) 설명·안내 문서 (기본)
```markdown
# <제목: 무엇을 · 어떻게, 30자 안>

> 이 문서는 <누가> <무엇을 할 때> 읽는 문서예요. 마지막 확인: <YYYY-MM-DD>

## 요약
- <핵심 3줄 안>

## 배경
<왜 이 문서가 필요한지 2~4문장>

## 내용
### <소제목>
<본문. 표·목록 위주>

## 자주 묻는 것
- **<질문>** — <답>

## 참고
- <관련 문서·파일·저장소 위치>
```

### 2) 결정 기록 문서
```markdown
# [결정] <결정한 내용> (<YYYY-MM-DD>)

| 항목 | 내용 |
|---|---|
| 상태 | 결정됨 / 검토 중 / 바뀜 |
| 결정한 사람 | <이름·역할> |
| 관련 미션 | <미션> |

## 배경
## 고려한 안
| 안 | 좋은 점 | 아쉬운 점 |
|---|---|---|
## 결정과 이유
## 이어서 할 일
```

### 3) 회의록
```markdown
# <YYYY-MM-DD> <회의 이름> 회의록

- 참석: <이름들>
- 목적: <한 줄>

## 논의한 것
## 결정된 것
## 할 일
| 할 일 | 담당 | 기한 |
|---|---|---|
```

## 쓰는 법
- 제목은 검색했을 때 바로 알아볼 수 있게, 날짜가 중요한 문서는 날짜를 넣는다.
- 한 절은 한 화면 안. 길면 소제목으로 나눈다. 긴 설명보다 표와 목록을 쓴다.
- 강조는 **굵게**만 쓴다. 색·글자 크기 꾸밈은 하지 않는다(붙여 넣을 때 깨진다).
- 정보 상자가 필요하면 `> 참고:` `> 주의:` 로 시작하는 인용문으로 쓴다(위키에서 정보 패널로 바꾸기 쉽다).
- 사실은 작업 폴더·참고 폴더에서 확인한 것만 쓰고, 근거 위치를 "참고"에 남긴다. 모르는 것은 "확인 필요"로 둔다.
- 결과는 이 과제의 시안 폴더에 `위키_<제목>.md` 로 만든다. 워드로 달라는 지시가 있으면 rano-docx 스킬로 같은 구성을 만든다.
- 비밀 값, 내부 서버 주소·계정, 개인 정보는 넣지 않는다.
