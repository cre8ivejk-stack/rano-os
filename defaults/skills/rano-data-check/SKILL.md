# 데이터 점검표 (rano-data-check)

데이터를 **고치지 않고** 점검만 한다. 고칠 일이 있으면 점검 결과를 근거로 리더에게 올린다.

## 점검 순서 (빠짐없이, 이 순서대로)
1. **범위**: 어떤 데이터(파일·표·쿼리), 어떤 기간, 어떤 대상(사업장·계량기)을 봤는지 먼저 적는다.
2. **빠진 기간**: 기대 간격(15분·1시간·하루·한 달)을 정하고, 빠진 구간을 시작~끝으로 모은다.
3. **중복**: 같은 대상·같은 시각이 두 번 이상 있는지.
4. **단위**: kWh·MWh·Wh, kW·MW, 원·천원이 섞였는지. 값 크기가 갑자기 1000배 차이 나면 단위 의심.
5. **튀는 값**: 0·음수·빈 값, 같은 대상의 평소 범위(중앙값 기준 아래위 3배 등)를 크게 벗어난 값. 기준을 함께 적는다.
6. **합계 맞추기**: 하위 합계와 상위 합계(시간별 합 = 일 합, 계량기 합 = 사업장 합)가 맞는지. 차이와 비율을 적는다.
7. **시간대**: KST/UTC 섞임, 월말·연초(1~3월) 날짜 경계, 서머타임 없는지.

## 결과 틀
```markdown
# 데이터 점검 결과 — <대상> (<기간>)

| 점검 | 결과 | 건수 | 예시(최대 3개) |
|---|---|---|---|
| 빠진 기간 | 이상 있음 / 없음 | 3 | 2026-10-03 01:00~03:00 … |
| 중복 | | | |
| 단위 | | | |
| 튀는 값 | | | |
| 합계 맞추기 | | | |
| 시간대 | | | |

## 판단
- <가장 먼저 볼 문제와 이유>

## 근거
- 본 파일·표·쿼리, 실행한 명령
```

## 방법
- 파일이면 문서 도구 파이썬(`$RANO_PY`)으로 읽어 센다(실행은 승인함). 큰 파일은 일부만 보지 말고 전체 건수를 센다.
- DB 는 **읽기(SELECT)만** 한다. 쓰기·지우기 쿼리는 쓰지 않는다.
- 결과 파일은 이 과제의 시안 폴더에 `데이터점검_<대상>_<YYYYMMDD>.md` 로 만든다. 표가 크면 rano-xlsx 스킬로 엑셀을 함께 만든다.
- 비밀 값(접속 정보·토큰)은 결과에 쓰지 않는다.
