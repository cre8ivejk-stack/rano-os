# 인수인계 문서 (rano-handover)

처음 맡는 사람이 이 문서 하나로 첫날 일을 시작할 수 있게 쓴다.

## 모을 곳 (읽기만)
- 미션 헌장(charter.md), 팀 편성(team.md), 미션 기억(memory/*.md), 결과물 목록(outputs.md)
- 작업 폴더의 README·규칙 파일(CLAUDE.md, AGENTS.md)·폴더 구조(맨 위 2단계까지)
- 최근 커밋(`git log -20 --oneline`)

## 틀
```markdown
# <미션·업무> 인수인계 (<YYYY-MM-DD> 기준)

## 이 일은
<목적 2~3문장. 누구를 위해 무엇을 하는지>

## 어디에 있나
| 무엇 | 위치 |
|---|---|
| 작업 폴더 | |
| 참고 자료 | |
| 결과물 | |

## 지켜야 할 규칙
- <규칙 파일 요약 3~7개. 특히 하면 안 되는 것>

## 지금 진행 중인 일
| 일 | 상태 | 다음 할 일 | 막힌 것 |
|---|---|---|---|

## 최근 결정
- <날짜> <결정> — 이유

## 자주 하는 일 하는 법
1. <일>: <순서 요약>

## 조심할 것
- <배포·데이터·비밀 관련 주의>

## 물어볼 곳
- <사람·문서>
```

## 지킬 것
- 사실은 위 "모을 곳"에서 확인한 것만 쓰고, 모르는 칸은 "확인 필요"로 남긴다.
- 비밀 값·계정·내부 주소는 넣지 않고 "어디에 있는지"만 적는다(예: "운영 접속 정보는 담당자에게").
- 결과는 시안 폴더에 `인수인계_<미션>_<YYYYMMDD>.md` 로 만든다. 워드가 필요하면 rano-docx 스킬로 같은 구성을 만든다.
