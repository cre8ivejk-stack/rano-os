# 절감 계산 근거표 (rano-savings-basis)

숫자 하나하나가 **어디서 왔는지** 다시 따라갈 수 있게 남긴다. 확인하지 못한 숫자는 지어내지 않고 "가정"으로 표시한다.

## 순서
1. 무엇을 계산하는지 한 문장으로 적는다(예: "A 사업장 10월 피크 이동으로 줄어든 전기요금").
2. 입력값을 모두 표로 적는다: 값, 단위, 기간, 출처(파일·표·문서 위치), 확인 여부.
3. 계산식을 글과 식으로 적는다. 중간값도 적는다.
4. 결과와 함께 **민감도**(단가 ±10%, 사용량 ±10% 일 때 결과)를 적는다.
5. 가정과 한계를 적는다.

## 틀
```markdown
# 절감 계산 근거 — <무엇> (<기간>)

## 결과
- <결과 값과 단위> (확인된 입력만 / 가정 포함)

## 입력값
| 항목 | 값 | 단위 | 기간 | 출처 | 확인 |
|---|---|---|---|---|---|
| 사용량(전) | | kWh | | | 확인 / 가정 |
| 사용량(후) | | kWh | | | |
| 단가 | | 원/kWh | | 요금표 위치 | |

## 계산
1. <식> = <중간값>
2. <식> = <결과>

## 민감도
| 바꾼 것 | 결과 |
|---|---|
| 단가 −10% | |
| 단가 +10% | |

## 가정과 한계
- <가정> — 이유
```

## 지킬 것
- 요금 단가는 계절·시간대(경부하·중간·최대)·기본요금을 구분한다. 한 가지 평균 단가로 뭉치면 가정으로 표시한다.
- 단위를 바꿀 때(MWh→kWh, 천원→원) 식에 그 단계를 적는다.
- 계산은 문서 도구 파이썬(`$RANO_PY`)이나 엑셀 수식으로 하고, 손으로 어림한 값은 쓰지 않는다. 엑셀로 낼 때는 rano-xlsx 스킬로 입력·계산·결과 시트를 나눈다.
- 결과 파일은 이 과제의 시안 폴더에 `절감근거_<무엇>_<YYYYMMDD>.md` 로 만든다.
